# 隐私与交付

## 数据分层

- 原始层：账单、旅行记账、完整账号和交易号。只在用户授权的本地目录处理，不上传、不打包。
- 审计层：清洗明细和匹配证据。默认仅本地交付，可保留交易号用于复核。
- 展示层：Excel 总览和网页。公开或分享版本只保留聚合数据及脱敏明细。
- Skill 层：只能包含通用规则、代码和空模板，绝不包含任何一次分析的数据或结论。

## 分享版必须移除

- 姓名、昵称、手机号、身份证号、邮箱、银行卡号、账号尾号组合；
- 交易号、商户订单号、备注原文、详细地址、学校/公司等可识别信息；
- 原始账单、分析生成的 CSV/JSON/XLSX/PDF、截图和数据库；
- 本机绝对路径、云盘路径、网站项目 ID、部署地址和访问令牌；
- 用户特有的分类关键词、亲属姓名、商户白名单和具体金额。

## 发布前检查

对准备分享的目录运行 `scripts/privacy_audit.py`。它会检查常见个人标识、绝对路径、疑似原始数据文件和大文件。扫描通过不等于绝对匿名；仍要人工抽查网页标题、图表标签、源代码内嵌 JSON 和压缩包文件列表。

若要公开网站，先生成一份新的脱敏构建，不要直接发布本地审计版。除非用户明确授权，Skill 不得自行上传、部署、发消息或修改外部系统。

## 建议交付结构

```text
output/
  个人财务全量分析.xlsx
  dashboard/index.html
  audit/
    cleaned_transactions.csv
    dedupe_audit.csv
    refund_matches.csv
    aa_offsets.csv
    privacy-report.json
```

分享 Skill 时只打包 Skill 目录本身，不要把 `output/` 一同压缩。
